## OKNO
### ОКНО - Оценка Космической Неблагоприятной Обстановки

Продукт представляет собой API-сервис, собирающий данные с API NASA (требуется
ключ для неограниченного доступа), Socrates и других API-эндпоинтов для оценки
степени неблагоприятности обстановки с точки зрения внекорабельной
деятельности на МКС. Учтены такие факторы, как космическая погода
(зарегистрированные солнечные вспышки донедельной давности, Kp-индекс и прочее)
и зарегистрированные приближающиеся космические объекты, такие как космический
мусор, спутники и т.д.

Сервис наделён возможностью ранжирования массива окон по неблагоприятности.
Подробнее можно узнать, проанализировав эндпоинт /docs формата OpenAPI на
движке Swagger UI, или углубившись в код сервиса. Полноценная документация
будет предоставлена позже.

Сервис склонен к кэшированию ответов в локальной базе даных в корне, okna.db.
Там сожержатся данные, полученные от разнообразных эндпоинтов - NASA Open APIs,
Socrates и др. используемых.

Могут проявляться трудности с доступом к API NASA из-за предположительной
блокировки по GeoIP. (в случае таковой эндпоинт возвращает HTTP 403).
Рекомендуется использовать VPN, прокси или любой другой способ подмены
IP-адреса для обхода блокировки.

### Как запустить сервис?

На Linux:
1. Скачайте репозиторий.
2. Перейдите в корень репозитория, разверните виртуальную среду и скачайте
   зависимости:
    ```bash
    python -m venv .venv
    pip install -r requirements.txt
    ```
3. Заполните .env следующим образом:
    ```.env
    NASA_API_KEY=yourkeyhere

    ```
4. Опционально запустите скрипт заполнения базы данных отчётами за период
   01.05.2024-30.06.2024. Изначально данный период покрыт отчётами от 
   19.09.2026, но могут появиться новые:
   ```bash
   python ./scripts/populate_db.py
   ```
5. Теперь, чтобы запустить сервис, запустите скрипт
    ```bash
    ./prodstart.sh
    ```

Для остановки сервиса достаточно нажать Ctrl+C, и FastAPI закончит работу после
обработки всех принятых запросов. Для повторного запуска сервиса достаточно
перейти в корень проекта и повторить четвёртый шаг.

После запуска подключиться к интерфейсу сервиса можно через браузер. За ссылкой
обратитесь к системному администратору, настраивающему сервис.
